User Story Map
Activity: Ask Health Question
User Stories
As a caregiver, I want to ask a health question using my voice so that I can receive health advice.
As a caregiver, I want the application to read advice aloud so that I can use it even if I struggle to read.
As a caregiver, I want emergency symptoms to be detected immediately so that I can seek urgent medical help.
As a caregiver, I want advice to remain available without internet access so that I can use the application in rural areas.
As a caregiver, I want query history stored so that I can review previous consultations.
Acceptance Criteria
Voice queries are successfully converted to text.
Health advice is displayed and spoken aloud.
Emergency symptoms trigger urgent referral advice.
Offline advice works without internet connectivity.
Query history is stored and retrievable.
