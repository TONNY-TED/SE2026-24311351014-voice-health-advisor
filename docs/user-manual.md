# VoiceHealth User Manual

## Purpose

This manual describes how a user interacts with VoiceHealth.

## Voice input

1. Tap the microphone.
2. Speak naturally.
3. Live waveform and partial text update.
4. After the silence timeout, the app finalizes and analyzes.

## Text input

1. Type a health question.
2. Press Analyze & Recommend.

## States

- Idle: tap microphone to speak.
- Listening: live waveform and status.
- Processing: analysis.
- Result: advice.
- Error: retry.

## Troubleshooting

- Allow microphone permission.
- Check network for speech recognition.
- Retry after errors.
